ONE DASHBOARD

Everything important, explained as you go.

Site Gateway keeps the everyday path simple while leaving room for advanced Caddy controls when you need them.

⌂

Hosted Sites

Upload a folder or ZIP, choose a port, add a primary domain and aliases, and publish static files with clear status feedback.

⇄

Proxy Hosts

Point domains at Plex, Jellyfin, Vaultwarden, or any HTTP service. TLS, HSTS, access lists, and advanced options stay discoverable.

↗

Redirect Hosts

Send one or more domains to a canonical destination with the same card, icon, status, and editing workflow.

◈

Access Lists

Combine login accounts, groups, network rules, and explicit host assignments in one reusable protection policy.

▣

Certificates

Track domain readiness, issuer, expiration, renewal health, and the Caddy-managed HTTPS lifecycle.

◌

Backups & restore

Create configuration or complete archives, download them locally, store scheduled copies in /data/backups, and recover safely.

A CALMER WORKFLOW

Defaults first. Advanced controls when they matter.

Create a route in a few fields, then open Advanced options only when the service calls for them.

01

Create a route

Choose Hosted, Proxy, or Redirect and follow the plain-language wizard.

02

Secure the domain

Caddy handles automatic HTTPS while Site Gateway reports readiness and problems.

03

Protect and observe

Assign Access Lists, review logs, and see what is running from the dashboard.
