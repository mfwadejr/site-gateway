# Archive

Historical material preserved from the original `mfwadejr/site-gateway` repository, which was retired and deleted once this repo (`site-gateway2`) fully superseded it. Nothing in this folder is part of the active application.

- `legacy-brand/` — retired brand assets (icons, wordmarks, approved sign-off versions).
- `legacy-unraid/` — an unfinished Unraid Community Apps template from the old repo.

The old repo's full pre-v0.11.31 commit history and ~370 version tags (v0.4.0-alpha.1 through v0.11.30) were also imported and live on the `legacy-history` branch of this repo, and the real release notes for v0.4.0-alpha.1 through v0.9.0-alpha.1 were recreated as GitHub Releases here, continuing the same per-version-notes pattern used for this repo's own v0.12.0+ releases.
