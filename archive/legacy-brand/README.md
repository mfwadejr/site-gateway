# Legacy brand assets (archived)

These brand assets were created during the original `mfwadejr/site-gateway` repo's early alpha development. They are **no longer in active use** — retained here for historical/awareness purposes only, since that original repo has been deleted.

- `site-gateway-icon.svg` / `site-gateway-icon.png` — early compact icon.
- `site-gateway-lockup.svg` — early full wordmark.
- `site-gateway-icon-approved.png`, `site-gateway-lockup-approved.png`, `site-gateway-approved.png` — the "approved" sign-off versions of the above.
- `product-icon-v1.png` — an earlier product icon iteration.

The original `README.txt` describing these files (from the old repo) is included alongside them, unedited, for reference.

If site-gateway2's current branding ever needs to be compared against where it started, this is that starting point.
